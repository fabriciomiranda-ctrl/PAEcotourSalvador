## 🍃 Sobre o Projeto

O **EcoTravel** é uma plataforma interativa que transforma a maneira como as pessoas viajam. O objetivo principal é conectar turistas a destinos ecológicos, rotas de pegada de carbono zero e comércios locais que apoiam a sustentabilidade, além de outros pontos de interesses de caráter de mobilidade alimentação e serviços basicos. 

Através de uma interface gamificada, os usuários podem planejar suas viagens sabendo exatamente o impacto ambiental e social de suas escolhas, transformando o turismo em uma força positiva para o planeta.

---

## ✨ Principais Funcionalidades

- 🗺️ **Mapa Interativo:** Descubra hotéis eco-friendly, restaurantes "farm-to-table" e atrações sustentáveis avaliadas pela comunidade.
- 🎒 **Guias de Impacto Local:** Dicas culturais e de preservação ambiental específicas para cada região visitada, incentivando o respeito à comunidade local.

## 🛠️ Como Executar o Projeto

### Pré-requisitos
Antes de começar, você precisará ter instalado em sua máquina as seguintes ferramentas:
- [Git](https://git-scm.com)
- [Node.js](https://nodejs.orgen/)
- Um gerenciador de pacotes como o **npm** ou **yarn**.

### Passos para Instalação

1. Clone este repositório:
```bash
git clone https://github.com
```

2. Acesse a pasta do projeto:
```bash
cd ecotravel
```

3. Instale as dependências:
```bash
npm install
```

4. Crie um arquivo `.env` na raiz do projeto e adicione suas chaves de API (exemplo):
```env
MAPBOX_API_KEY=sua_chave_aqui
DATABASE_URL=seu_link_do_banco_aqui
```

5. Inicie o servidor de desenvolvimento:
```bash
npm start
```
O aplicativo abrirá automaticamente no seu navegador ou estará pronto para ser testado no emulador.
